# EcoIA Extension

Uma extensão para navegadores Chromium que estima o consumo energético e o impacto ambiental durante o uso de ferramentas de Inteligência Artificial.

## Objetivo

Desenvolver uma extensão capaz de monitorar o uso de ferramentas de IA e estimar:

- consumo energético (Wh)
- emissão estimada de CO₂
- consumo indireto de água
- estatísticas de utilização

## Tecnologias

- JavaScript
- HTML
- CSS
- Chrome Extension Manifest V3
